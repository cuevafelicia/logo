Brand guidelines

FC Studio Logo

A hand-drawn "f" swash flows into a "c" stroke and lands on an orbiting circle to signify continuous iteration and curiosity.

This page presents the four official variations, how to size them, and which one to use on light or dark backgrounds. Use the toggle in the top bar to see how the page itself switches logos between themes.

The system

Logo Variations

Every variation is shown on a light and a dark background so you can see where it works and where it does not.

1. Black and White

Light and Dark
Black on light
White on dark

When to use

  • One-color printing: fax, newspaper, stamps, engraving, laser cutting, embroidery.
  • Photocopies and documents that may be printed in grayscale.
  • Over photography, where color would clash. Use black on light images and white on dark images.

Configuration

  • Two files: fc-studio-logo-black.svg for light backgrounds, fc-studio-logo-white.svg for dark ones.
  • Flat color only - no tints, gradients or partial transparency.
  • Aspect ratio 386 : 218 (about 1.77 : 1).

2. Color (primary)

Light Backgrounds
On white
On Alice Blue
Avoid - on Midnight Violet

When to use

  • The default choice. Use it whenever full color is possible on a white or Alice Blue background.
  • Website headers in light mode, business cards, letterhead, slide title pages, social banners.

Configuration

  • Dark Raspberry mark, Midnight Violet wordmark, Dark Cyan and Light Gold accents.
  • Never place it on Midnight Violet, Dark Rapberry, or any dark background: the Dark Raspberry mark and Midnight Violet text disappear (third tile). Switch to the reverse version instead.

3. Reverse

Dark Backgrounds
On black
On Dark Cyan
On white

When to use

  • Dark-mode websites and apps (this page switches to it in dark mode).
  • Dark merchandise, stickers, and app splash screens.
  • Because the Alice Blue artwork sits inside its own rounded Midnight Violet panel, it also holds up on light or busy backgrounds as a badge.

Configuration

  • Alice Blue mark and wordmark, Dark Cyan and Light Gold accents, on a Midnight Violet (#231123) rounded rectangle.
  • Keep the panel; do not strip it out and drop the light artwork on a pale background.
  • Aspect ratio 473 : 343 (about 1.38 : 1).

Browser tab in light and dark chrome. This page's own tab uses the same file.

When to use

  • Browser tabs, bookmarks, and home-screen shortcuts.
  • Social profile pictures, app icons, and any square space where the wordmark would be unreadable.

Configuration

  • Square 512 x 512 artboard, mark only - the wordmark is dropped because it cannot be read at 16 px.
  • The mark is cropped tight and sits on its own Alice Blue rounded tile, so it stays visible on both light and dark browser chrome.
  • Link it with <link rel="icon" type="image/svg+xml"> (see Code).

Scale

Sizing and Clear Space

The files are vector, so they scale to any size. These limits keep the tagline and the fine orbit ring legible.

Recommended widths (primary logo)

Clear Space

Rules

Choosing and Using the Right Version

Light Backgrounds

White, Alice Blue, Light Gold, or light photography.

  1. Color logo (first choice)
  2. Black logo (one-color jobs)
  3. Reverse logo as a badge

Dark Backgrounds

Midnight Violet, Dark Raspberry, black, dark mode, or dark photography.

  1. Reverse logo (first choice)
  2. White logo (one-color jobs)
  3. Never the color logo

Do

  • Scale proportionally - lock the aspect ratio.
  • Use the SVG files from this page so edges stay crisp at every size.
  • Respect the clear space and the minimum sizes.
  • Swap versions automatically with the page theme (see Code).

Don't

  • Stretch, skew, rotate, or outline the logo.
  • Recolor it with colors outside the palette.
  • Add drop shadows, glows, or gradients.
  • Separate the mark from the wordmark, except in the favicon.

Implementation

Configuring the logo on the web

Favicon in the <head>

<link rel="icon" type="image/svg+xml" href="svg/favicon.svg">

Responsive size

<img src="svg/fc-studio-logo-color.svg"
     alt="FC Studio"
     style="width: clamp(140px, 30vw, 320px); height: auto;">

Follow the visitor's light / dark setting

<picture>
  <source srcset="svg/fc-studio-logo-reverse.svg"
          media="(prefers-color-scheme: dark)">
  <img src="svg/fc-studio-logo-color.svg"
       alt="FC Studio" width="240">
</picture>

The browser loads the reverse file only when the system is in dark mode, and the color file otherwise.
